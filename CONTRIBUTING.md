# Contributing

Use Node.js 22.12 or newer, then run `npm ci` and `npm run dev`.
Before sending a change, run `npm run check` and `npm run release:check`.

Keep flight independent of frame rate, retain the 500 million ly/s cap including combined movement, and preserve sub-sector coordinate precision. Black hole capture must check swept motion, work without targeting the hole, and remain locked until arrival.

Every independently visible permanent point must refer to a real catalogue entry. Distinguish measured facts, approximate distances, schematic geometry and fictional travel. Preserve catalogue attribution and CC BY-SA terms.

Do not commit credentials, browser storage, runtime logs, user MP3 files or system-voice recordings. Optional private media may be used locally but must not enter a public release. Add a focused regression test when fixing a consequential bug.
